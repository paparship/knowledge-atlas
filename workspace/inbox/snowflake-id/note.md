雪花算法（Snowflake）是一种分布式 ID 生成算法，将时间、机器编号和序号组合为一个 64 位整数，让多台机器能够独立生成唯一 ID。

## 计算方法

经典布局：

```text
0（1 位） | 时间差（41 位） | 机器编号（10 位） | 序号（12 位）
```

时间差是当前时间距离约定起点的毫秒数；机器编号区分不同生成节点；序号区分同一机器在同一毫秒内生成的多个 ID。

```text
ID = (时间差 << 22) | (机器编号 << 12) | 序号
```

左移为后面的字段腾出位置，按位或将各段拼接起来；例如时间差为 1、机器编号为 2、序号为 3，得到 `4194304 + 8192 + 3 = 4202499`。

## ID 特点

- **唯一性**：由时间、机器编号和序号共同保证；机器编号需互不冲突，时钟回拨需由生成器处理，同一毫秒序号用尽后等待下一毫秒。
- **大体按时间递增**：时间位于高位，适合按生成时间粗略排序；多台机器生成的 ID 不代表严格的全局先后顺序。
- **数值大且稀疏**：ID 不连续，中间会有大量空缺，因此不适合直接作为 Bitmap 的位下标。

## 适用场景

适合订单、用户、消息等需要由多个服务实例生成唯一整数 ID 的场景；例如多台订单服务器各自在本地生成订单号，无需每次请求统一的数据库自增序号。
