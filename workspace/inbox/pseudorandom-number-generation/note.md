伪随机数生成器从种子初始化内部状态，按固定算法更新状态并产生输出；相同的算法、种子和调用顺序会得到相同序列。

## 1. 线性同余法（LCG）

只保存一个整数状态，每次做乘加取模，再把结果作为新状态和输出。

```text
下一状态 = (a × 当前状态 + c) % m

例如 a = 5、c = 1、m = 16，种子为 3：
(5 × 3 + 1) % 16 = 0
(5 × 0 + 1) % 16 = 1
(5 × 1 + 1) % 16 = 6

序列：3 → 0 → 1 → 6 → 15 → … → 3
```

这个例子经过 16 步回到原状态，之后整段序列重复，周期为 16；虽然 0～15 都会出现，奇偶却严格交替，连续输出之间有明显规律。

**适用场景**：简单、资源受限且对统计质量要求不高的随机过程，或理解伪随机机制；优点是快、省空间，取舍是参数敏感，低位和连续输出可能有明显相关性。

## 2. Xorshift

保存一个非零状态，依次对它做固定的移位与异或运算，最后的结果既作为输出，也留作下一次调用的状态。

一个经典的 32 位版本如下，每步只保留低 32 位：

```text
x = 当前状态
x = x XOR (x 左移 13 位)
x = x XOR (x 右移 17 位)
x = x XOR (x 左移 5 位)
保存 x，并输出 x

种子为 1 时：1 → 8193 → 8193 → 270369
本次输出 270369，下次从 270369 开始重复上述步骤。
```

这个版本使用非零种子时，周期为 2³²−1；13、17、5 是选定的参数组合，零状态会一直产生零。

**适用场景**：需要小状态、低计算开销的一般游戏随机过程或轻量模拟；优点是状态小、计算快，基础版本存在位级线性规律。

## 3. PCG

将“更新状态”和“生成输出”分开：内部用线性同余法推进状态，对外输出前再进行变换。

以常见的 PCG32 XSH-RR 为例：

```text
① 记录旧的 64 位状态 old。
② 更新状态：
   state = (old × 6364136223846793005 + 奇数增量) % 2⁶⁴
③ 生成待输出的 32 位数：
   bits = 取低32位(((old 右移18位) XOR old) 右移27位)
④ 从 old 的最高5位取得旋转位数，范围为 0～31。
⑤ 将 bits 按这个位数循环右旋，得到本次输出。
```

状态递推决定序列如何前进，输出变换改善直接输出同余状态时的统计性质；PCG32 每条流的状态周期为 2⁶⁴。

**适用场景**：游戏随机、程序化生成和一般模拟，需要兼顾速度、较小状态和统计质量时；固定种子与流参数可以复现序列。

## 4. 梅森旋转算法（MT19937）

维护 624 个 32 位整数构成的状态数组，先更新一批状态，再依次产生输出。

```text
① 用种子初始化状态数组。
② 更新状态：
   以第一个位置为例，拼接 state[0] 的最高1位和
   state[1] 的低31位，得到 y。
   将 y 右移1位，与 state[397] 异或；
   如果 y 原来为奇数，再异或常数 0x9908B0DF。
   按算法规定的顺序处理其余位置，完成本轮更新。
③ 依次取出更新后的状态 x，做输出变换：
   x = x XOR (x 右移11位)
   x = x XOR ((x 左移7位) & 0x9D2C5680)
   x = x XOR ((x 左移15位) & 0xEFC60000)
   x = x XOR (x 右移18位)
④ 输出 x；输出变换不写回状态数组。
⑤ 这一批状态用完后，再更新数组，继续输出。
```

这里的固定参数经过数学设计，使状态周期达到 2¹⁹⁹³⁷−1，并具有良好的多维均匀分布性质；保存状态约需 2.5 KB。

**适用场景**：一般科学模拟、蒙特卡洛采样，以及需要复现既有 MT 随机序列的程序；取舍是状态比前几种方法大，仍存在可分析的线性结构。
