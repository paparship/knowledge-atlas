伪随机数生成器从种子初始化内部状态，按固定规则更新状态并产生输出。相同的算法、种子和调用顺序会得到相同序列；理解它可以从“怎样变换一个数”开始。

## 1. 变换一个数的基本操作

下面用 8 位无符号整数演示：每位只能是 0 或 1，最右边是最低位；运算结果只保留低 8 位。

### 移位：改变比特所在的位置

左移把比特向左搬，右侧补 0；逻辑右移向右搬，左侧补 0，移出边界的位丢弃。

```text
原值：       00101101 = 45
左移 1 位：  01011010 = 90
右移 2 位：  00001011 = 11
```

### 异或：用另一个数决定哪些位翻转

异或记作 XOR 或 ^：对应位相同得 0，不同得 1；因此与 0 异或保持原位，与 1 异或翻转原位。

```text
    00101101
XOR 00001011    原值右移 2 位的结果
  = 00100110 = 38
```

这样得到的新数，每一位可能同时依赖原数中两个不同位置的位，这就是一种具体的“混合”。

### 掩码：选出指定位置的位

按位与记作 &：只有两个对应位都是 1，结果才为 1；掩码中为 1 的位置保留，为 0 的位置清除。

```text
    10110110
  & 00001111    掩码：只保留低 4 位
  = 00000110 = 6
```

### 循环旋转：把移出去的位接到另一端

```text
原值：       101100|01
循环右旋 2 位：01|101100 = 01101100
```

旋转重新排列位的位置，所有位都保留下来；它本身是确定的操作，不产生新的随机性。

### 乘加取模：让数值在有限范围内递推

```text
下一状态 = (5 × 当前状态 + 1) % 16

当前状态 3： (5 × 3 + 1) % 16 = 0
当前状态 0： (5 × 0 + 1) % 16 = 1
当前状态 1： (5 × 1 + 1) % 16 = 6
```

取模保留除法的余数，这里将状态限制在 0～15。

## 2. 从数字变换到连续输出

固定输入经过固定变换，输出始终相同。要不断生成数字，需要保存并更新内部状态：

```text
种子 → 初始化状态
每次调用：读取状态 → 计算输出，并更新状态 → 留给下一次调用
```

**状态更新**决定序列怎样前进；**输出变换**决定怎样把状态转换成对外提供的数。两者可以是同一个过程，也可以分开设计，下面的 PCG 就将它们分开。

判断生成器时，要区分三个性质：

- **周期**：内部状态经过多少步回到起点，之后整段序列重新播放；单个输出值重复不等于状态已经重复。
- **统计性质**：数字的分布是否均匀，连续输出是否存在容易识别的规律。
- **不可预测性**：观察已有输出后，能否推算后面的数字。

周期长并不自动保证后两项；这些固定运算也不会增加新的随机信息。

## 3. 线性同余法：直接用递推状态生成数字

公式是 next = (a × state + c) % m，继续使用上面的参数：

```text
3 → 0 → 1 → 6 → 15 → 12 → 13 → 2
  → 11 → 8 → 9 → 14 → 7 → 4 → 5 → 10 → 3
```

这里经过 16 步回到 3，周期为 16；0～15 各出现一次，但奇偶严格交替，因此用输出 % 2 模拟抛硬币，就会得到固定交替的结果。

原因是乘以奇数 5 保持奇偶性，加 1 翻转奇偶性，对偶数 16 取模仍保持奇偶性：**单个数字出现均匀，连续数字之间仍可能有明显规律。**

LCG 简单、快、只保存一个整数；参数选择影响周期与相关性，以 2 的幂为模时尤其要注意低位的短周期。

## 4. Xorshift：反复移位，再与自身异或

一个经典的 32 位版本使用移位参数 13、17、5，状态必须非零；下面从 1 开始算一次，每步保留低 32 位：

```text
x = 1

x = x XOR (x 左移 13 位)
  = 1 XOR 8192
  = 8193

x = x XOR (x 右移 17 位)
  = 8193 XOR 0
  = 8193

x = x XOR (x 左移 5 位)
  = 8193 XOR 262176
  = 270369
```

输出 270369，并将它作为下一次调用的状态；这个参数组合在非零状态下的周期为 2³²−1。

Xorshift 状态小、运算少；基础版本仍有位级线性规律。移位参数需要筛选，任意组合可能很快循环，零状态则会一直产生零。

## 5. MT19937：组合状态数组中的多个位置

MT19937 保存 624 个 32 位整数，通过组合不同位置的状态进行更新，再对取出的状态做输出变换。以更新第一个位置为例，人为选取以下状态来演示实际公式：

```text
state[0] = 0，state[1] = 1，state[397] = 0

① 拼接 state[0] 的最高 1 位和 state[1] 的低 31 位
   得到 y = 1

② y 逻辑右移 1 位，再与 state[397] 异或
   (1 >> 1) XOR 0 = 0

③ y 原来为奇数，再异或固定常数
   0 XOR 0x9908B0DF = 0x9908B0DF
   这就是更新后的 state[0]
```

0x 表示十六进制。取这个新状态作为 x，进行四次输出变换；后一步使用前一步的结果：

| 运算（32 位无符号计算） | 结果 |
|---|---|
| 初始 x | 0x9908B0DF |
| x XOR (x 右移 11 位) | 0x991B91C9 |
| x XOR ((x 左移 7 位) & 0x9D2C5680) | 0x1413D549 |
| x XOR ((x 左移 15 位) & 0xEFC60000) | 0xFE97D549 |
| x XOR (x 右移 18 位) | 0xFE97EAEC |

最终输出十进制 4271368940，输出变换的结果不写回状态数组；一批状态依次用于输出，用完后再更新状态数组。

MT19937 的周期为 2¹⁹⁹³⁷−1，状态占用约 2.5 KB，具有良好的多维均匀分布性质；它仍具有可分析的结构，不具备密码学不可预测性。

## 6. PCG：状态递推与输出变换分开

PCG 将线性同余递推与输出变换组合。以常见的 PCG32 XSH-RR 为例：

```text
old = state

# 更新下一次调用要用的 64 位状态
state = (old × 6364136223846793005 + oddIncrement) % 2⁶⁴

# 用旧状态生成本次输出
bits = 取低32位(((old 右移18位) XOR old) 右移27位)
rotation = old 右移59位       # 取最高5位，得到0～31
output = 将 bits 循环右旋 rotation 位
```

这里的“打乱”就是可明确计算的移位、异或和循环旋转：状态的一部分决定旋转多少位，重新安排输出位的位置；前面的同余递推负责持续产生新状态，后面的变换改善输出的统计性质。

PCG32 状态较小、速度快，每条流的状态周期为 2⁶⁴；它适合一般随机采样，但不作为密码学安全生成器使用。

## 7. 固定参数的意义与方法对比

这些算法中的乘数、移位数、掩码和数组长度，是为周期与统计性质选定的参数。数学分析可以证明特定组合的周期或分布性质，统计检验用于检查输出规律；“做很多次位运算”本身不能保证随机质量。

| 算法 | 状态与更新方式 | 主要特点 |
|---|---|---|
| LCG | 一个整数，乘加取模 | 简单省空间，连续输出与低位可能显现规律 |
| 基础 Xorshift | 一个或多个整数，移位与异或 | 快、状态小，存在位级线性结构 |
| MT19937 | 624 个整数，数组递推与输出变换 | 周期极长、多维分布好，状态较大 |
| PCG32 | 64 位状态及流参数，同余递推与输出变换 | 状态较小，改善直接输出同余状态时的统计性质 |

这些方法都适用于理解确定性伪随机序列：固定种子可以复现；生成密钥、令牌等需要不可预测性的值时，使用操作系统提供的密码学安全随机接口。
