> 计算机网络 / HTTP

**HTTP 重定向通过重定向状态码和 Location 响应头，指引客户端向另一个地址发起请求。**

## 页面搬迁时如何跳转

用户访问旧页面：

```http
GET /old-page HTTP/1.1
Host: example.com

```

服务端告知页面已永久迁移：

```http
HTTP/1.1 301 Moved Permanently
Location: /new-page
Content-Length: 0

```

浏览器收到后，自动向同一站点的 `/new-page` 发起新请求，并更新地址栏、显示新页面。这个过程包含两次请求，页面导航由浏览器完成。

## 永久迁移与临时转向

- `301 / 308`：永久迁移，例如页面地址调整，或将 HTTP 地址统一转到 HTTPS。
- `302 / 307`：临时转向，例如将尚未登录的用户引导到登录页面。

这一区别用于表达原地址与新地址的长期关系，影响客户端、缓存和搜索引擎对地址的使用。

## 跳转后如何处理请求方法

- `307 / 308`：保留原请求的方法和正文。
- `303`：常用于 POST 提交成功后，以 GET 获取结果页面。
- `301 / 302`：原请求为 POST 时，客户端可能改用 GET。

## 页面导航与接口请求

普通页面导航遇到重定向时，浏览器自动请求新地址，并改变当前页面和地址栏。

`fetch()` 默认也会跟随重定向，但作用于这次接口请求，结果交给 JavaScript；需要让当前页面跳转时，由前端通过 `window.location` 等方式发起导航。
