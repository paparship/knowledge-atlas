Unity Profiler、Memory Profiler 和 Frame Debugger 分别从**一段时间内的帧耗时、某一刻的内存占用、一帧里的绘制顺序**观察游戏。

| 工具 | 能看到什么 | 三消游戏中的用法 |
| --- | --- | --- |
| **Unity Profiler** | 录制连续多帧，选中慢帧，在 CPU 时间线上查看各线程和函数的耗时。 | 一次连消突然掉帧，定位到对应帧，展开主线程，看耗时集中在消除逻辑、Spine 动画更新还是垃圾回收。 |
| **Memory Profiler** | 拍摄内存快照，对比两次快照中对象的数量、大小和引用关系。 | 在大厅拍一张，反复进出关卡再回大厅拍一张；如果棋子纹理持续增加，沿引用查是谁还持有它们。 |
| **Frame Debugger** | 捕获一帧，按顺序查看渲染事件，逐步看到每次绘制给画面添加了什么，以及使用的材质、纹理。 | 棋盘原本可以合批，插入特效后却多了几次 draw call；逐步查看绘制序列，确认哪一步切换了材质或纹理。 |

要判断优化是否有效，在同一台目标设备复现同一段操作，对比修改前后的帧耗时或内存占用。
