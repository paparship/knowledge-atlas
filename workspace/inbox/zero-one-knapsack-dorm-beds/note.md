有 1000 张床，每个班要么全搬，要么不搬。每个班的人数既是它占用的床位数，也是选它获得的入住人数。这是 **0/1 背包**，目标是在总人数不超过床位数的前提下，让入住人数最多。

## DP 数组与更新规则

`dp[c]` 表示用已经处理过的班级，在**最多占用 `c` 张床**的条件下，能安排的最多人数。开始时没有处理任何班，每个位置都是 0。

处理一个有 `size` 人的班，在每个放得下它的容量上比较两种方案：

- **不选这个班**，保留原来的 `dp[c]`。
- **选这个班**，先给它留出 `size` 张床，再加上之前的班用剩余容量能安排的 `dp[c - size]`。

**容量从大到小更新**，所以计算 `dp[c]` 时，下标更小的 `dp[c - size]` 还没被当前班更新。例如有 10 张床，只有一个 5 人班。如果从小到大更新，就会先把 `dp[5]` 改成 5，随后用它把 `dp[10]` 改成 10，相当于把同一个班算了两次。

## Python 实现

```python
def max_occupied_beds(class_sizes, capacity=1000):
    dp = [0] * (capacity + 1)

    for size in class_sizes:
        # 容量倒序，保证当前班只用一次
        for c in range(capacity, size - 1, -1):
            without = dp[c]
            with_class = dp[c - size] + size
            dp[c] = max(without, with_class)

    return dp[capacity]

print(max_occupied_beds([600, 510, 490]))  # 1000，选 510 人班和 490 人班
```

处理 `n` 个班、容量为 `C` 时，时间复杂度为 `O(n × C)`，空间复杂度为 `O(C)`。
