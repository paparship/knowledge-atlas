Draw call（绘制调用）是程序向图形接口提交的一次绘制指令，用指定的几何数据和绘制状态画出一批图元；合批是将多个物体的绘制组织到更少的调用中，降低 CPU 和驱动的提交开销。

## 什么情况下能合批

- **合并网格**：不同形状的物体也可以合批，例如使用兼容材质和绘制状态的桌椅，将网格合并后一起绘制。
- **实例化绘制**：重复使用同一个网格，例如一批相同模型的树，通过实例数据提供各自的位置、朝向、大小和颜色。
- **绘制状态兼容**：需要使用兼容的着色器、纹理绑定、透明混合和深度设置；必须切换这些状态时通常需要拆批，不同纹理有时可以通过图集或纹理数组统一。

## 主要取舍

- **提交开销与剔除粒度**：批次变少能减少提交开销，但合并成大网格后，一小部分可见就可能需要提交整批几何。
- **合并程度与独立管理**：网格合并后，单独移动、修改物体更麻烦；透明物体还可能受远近排序限制。

通常按空间邻近、绘制状态兼容、是否需要独立变化来分批；重复模型可采用实例化绘制。
