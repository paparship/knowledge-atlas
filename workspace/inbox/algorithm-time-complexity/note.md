时间复杂度描述输入规模 `n` 增大时，算法的执行时间如何增长。分析循环时，可以选定一个耗时固定的基本操作 `work()`，数清每轮做几次，再把各轮次数相加。`O` 给出增长的上界，`Θ` 给出紧确界，即上下界同阶。

## 四个基本例子

| 代码在做什么 | 基本操作的次数 | 时间复杂度 |
| --- | --- | --- |
| 数组按下标读取一个元素 | 1 次 | Θ(1) |
| 从头到尾扫描 n 个元素 | n 次 | Θ(n) |
| i 从 1 开始，每轮做一次 work()，然后翻倍，直到 i ≥ n | 执行 k 轮后 i = 2ᵏ，首次达到 n 需要 ⌈log₂ n⌉ 轮 | Θ(log n) |
| 对每个元素，都完整扫描一遍 n 个元素 | n 轮，每轮 n 次，共 n² 次 | Θ(n²) |

## 外层翻倍，内层次数也随之增长

```python
i = 1
while i < n:
    for j in range(i):
        work()
    i *= 2
```

取 `n = 10`，外层的 `i` 依次为 1、2、4、8，每轮分别调用 1、2、4、8 次，总共 15 次。这里虽然有两层循环，内层的长度却每轮都在变，所以要算的是各轮之和。

**先求和。** 设 `m` 是最后一次进入循环时的 `i`，总次数为 `S`。因为每项都是前一项的两倍，把整行乘以 2，两行就可以错位相减：

```text
2S =     2 + 4 + … + m + 2m
 S = 1 + 2 + 4 + … + m
```

从 2 到 m 的项全部抵消，得到 `S = 2S − S = 2m − 1`。

**再用输入规模 n 表示。** 最后一轮能进入循环，说明 `m < n`；翻倍后退出，说明 `2m ≥ n`。于是 `n − 1 ≤ S < 2n`，总次数随 n 线性增长，时间复杂度为 **Θ(n)**。
