游戏主循环每帧收集输入、推进游戏状态，并把当前状态画到屏幕上。以玩家滑动两枚棋子、触发三连为例：

| 阶段 | 这一帧做什么 |
| --- | --- |
| 1. 玩家输入 | 把玩家的滑动转成“交换这两格”的请求。 |
| 2. 时间步进 | 根据经过的时间，决定本帧推进多少游戏时间。 |
| 3. 游戏逻辑更新 | 交换棋子，判定三连，分数从 100 加到 130。 |
| 4. 物理与碰撞 | 按需推进物理对象；棋盘上的三连直接按格子判断。 |
| 5. 动画更新 | 推进消除动画，算出棋子和特效这一帧的姿势。 |
| 6. 表现与 UI 更新 | 启动分数滚动，更新这一帧的标签文字。 |
| 7. 渲染 | CPU 准备绘制命令，GPU 把棋盘和标签画进缓冲区。 |
| 8. 画面呈现与垂直同步 | 提交画好的缓冲区，显示器刷新时呈现这帧画面。 |

一次消除可以跨越多帧：规则在判定成功时加分，消除动画和分数滚动在后续帧继续播放。
