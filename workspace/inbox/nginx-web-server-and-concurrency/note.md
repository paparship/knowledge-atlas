NGINX 可以作为 Web 服务器直接返回静态文件，也可以作为反向代理，接收浏览器请求并转发给后端。

## 在应用中负责什么

以知识库为例，浏览器可以直接访问 Node，因为 Node 本身能接收 HTTP 请求。加入 NGINX 后，可以让它作为统一入口，处理 HTTPS，直接返回网页和脚本，并把保存笔记的 API 请求转发给 Node。Node 负责校验和保存，NGINX 再把响应传回浏览器。

## 一个工作进程怎样处理多个连接

NGINX 可以启动多个工作进程，每个进程由一个线程运行网络事件循环。请求 A 转发到后端后，线程可以先处理已经能读写的请求 B。等 A 的回复到达，线程收到通知，再继续处理 A。

单个工作进程通过事件循环交替推进多个连接。多个工作进程则可以在不同 CPU 核上同时运行。
