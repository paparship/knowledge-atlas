**客户端与服务端的交互方式，可以按谁发起交互、请求如何等待、连接是否持续以及数据传递方向来区分。**

| 方式 | 交互机制 | 数据方向 |
| --- | --- | --- |
| 轮询：定时轮询 | 客户端定期发起请求，服务端每次返回当前结果 | 客户端请求，服务端响应 |
| 轮询：长轮询 | 客户端发起请求，服务端等到有新数据或超时再响应，客户端收到后再次请求 | 客户端请求，服务端延迟响应 |
| SSE | 客户端建立请求后，服务端通过持续的 HTTP 响应发送事件 | 服务端持续向客户端推送 |
| WebSocket | 握手建立持久连接，双方通过连接主动发送消息 | 双向消息传递 |
