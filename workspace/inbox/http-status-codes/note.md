HTTP 状态码表示一次请求的处理结果。先看首位数字判断类别，再根据具体状态码定位问题。

| 类别 | 常见状态码 |
|---|---|
| 2xx 成功 | 200 请求成功，201 创建成功，204 成功且无响应正文 |
| 3xx 重定向与缓存验证 | 301 永久重定向，302 临时重定向，304 资源未修改，可复用缓存 |
| 4xx 请求相关错误 | 400 请求有误，401 缺少有效身份凭证，403 拒绝访问，404 找不到资源，410 资源已永久移除，429 请求过多 |
| 5xx 服务端错误 | 500 服务器内部错误，502 网关收到无效的上游响应，503 服务暂不可用，504 网关等待上游超时 |

例如，浏览器用 If-None-Match 带上缓存版本的 ETag。服务端确认资源未修改后返回 304，浏览器继续使用缓存中的响应正文。
